# Local Codex CLI Artifact Runner

This runbook describes the local MBP 2015 flow for consuming task prompt
artifacts generated by GitHub Actions. It bridges repository task automation to
manual or semi-manual local Codex CLI execution.

The scripts in `scripts/ops` do not auto-run Codex yet. They list artifacts,
download the selected prompt, and print the recommended Codex CLI command.

## Prerequisites

1. Install and authenticate the GitHub CLI:

   ```bash
   gh auth status
   ```

2. Install and authenticate Codex CLI.
3. Pull the latest `develop` locally:

   ```bash
   git switch develop
   git pull --ff-only origin develop
   ```

## Repository Isolation

CarbonOps-API local runner scripts must be run from the CarbonOps-API repository
only. They verify the current git repository and refuse to run unless
`origin` points to `ktalpay/CarbonOps-API`.

CarbonOps-Parser and CarbonOps-API must use separate repository roots on the
MBP 2015. Do not reuse Parser worktrees for API tasks, and do not delete Parser
worktrees from API scripts. API helper scripts anchor `.agent-handoff/` paths to
the resolved CarbonOps-API repo root and must not touch sibling repositories.

## Flow

1. Run Ready Task Dispatch Discovery from GitHub Actions if a fresh prompt
   artifact is needed.
2. List recent task prompt artifacts:

   ```bash
   scripts/ops/list-task-prompt-artifacts.sh
   ```

3. Download the selected task prompt artifact by artifact id or task id:

   ```bash
   scripts/ops/download-task-prompt-artifact.sh API-OPS-006
   ```

4. Inspect the generated prompt and metadata under:

   ```text
   .agent-handoff/downloads/
   ```

5. Prepare the local Codex CLI command:

   ```bash
   scripts/ops/prepare-codex-task-run.sh .agent-handoff/downloads/<artifact>/<TASK-ID>-prompt.md
   ```

6. Run the printed Codex CLI command when ready.
7. Confirm Codex creates a task branch and opens a PR to `develop`.
8. Review and merge the PR manually.
9. After merge, Agent Task Watcher updates the task issue status and can trigger
   downstream ready-task discovery.

## Safety Notes

- `.agent-handoff/` is ignored by git and must not be committed.
- Scripts refuse to run outside the CarbonOps-API git repository.
- Scripts anchor downloaded prompt artifacts under the CarbonOps-API repo root.
- The helper scripts do not mutate GitHub issues.
- The helper scripts do not create branches, commits, or pull requests.
- The helper scripts do not call Codex automatically.
- PR review and merge remain user-owned.

## Scripts

- `scripts/ops/list-task-prompt-artifacts.sh`: lists recent
  `task-prompt-*` workflow artifacts.
- `scripts/ops/download-task-prompt-artifact.sh`: downloads and extracts a
  prompt artifact to `.agent-handoff/downloads/`.
- `scripts/ops/prepare-codex-task-run.sh`: validates a prompt file and prints
  the recommended Codex CLI command.

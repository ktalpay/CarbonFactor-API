# CarbonFactor API — Codex Cloud Run 01 — 2026-04-30

## Purpose

Initialize CarbonFactor API as a small, deterministic, testable API contract foundation for future carbon factor lookup and integration work.

This run should not build a production API. The goal is to establish conservative, local, testable contracts that can later connect to CarbonFactor Parser outputs.

## Current Repository Context

The repository is currently minimal and contains only a basic README. Treat this run as the API foundation sprint.

Related ecosystem context:

- CarbonFactor Parser exists as a separate repository and is being developed as deterministic carbon-factor parsing/data tooling.
- CarbonOps Assistant exists as a separate repository and is being developed as deterministic assistant/evaluation tooling.
- Do not import code from those repositories in this run.
- You may mention future integration points conservatively in documentation.

## Design Decision for This Run

Use Python standard library only for the first API contract foundation.

Do not add FastAPI, Flask, Django, database drivers, or web server dependencies yet.

Instead, define:

- API DTO/data contracts
- service-layer lookup behavior over in-memory sample data
- deterministic validation/error models
- OpenAPI-like documentation as Markdown, not generated server code
- tests proving contract behavior

A real HTTP server can be introduced later after contracts stabilize.

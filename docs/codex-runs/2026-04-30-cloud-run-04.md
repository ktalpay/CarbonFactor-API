# Task Queue

## CFA-014 — Explicit HTTP Query Validation

### Objective

Make supported `/factors` query parameters explicit and deterministic.

### Required Changes

Create or update:

```text
src/carbonfactor_api/http/query.py
src/carbonfactor_api/http/routes.py
tests/test_http_query.py
tests/test_http_routes.py
```

### Requirements

Supported `GET /factors` query parameters:

- `category`
- `activity`
- `region`
- `year`

Implement helper logic to:

- build a query dictionary from supported parameters
- detect unsupported query keys using FastAPI `Request` if needed
- preserve integer `year` behavior
- map invalid query behavior to the existing transport error envelope

Routes must still delegate to transport handlers.

### Tests

Add tests for:

- supported params pass through
- unsupported query param returns deterministic error envelope
- valid year works
- invalid year behavior is deterministic
- route still matches transport handler output for supported params

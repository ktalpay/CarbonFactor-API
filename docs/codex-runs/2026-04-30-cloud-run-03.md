# CarbonFactor API — Codex Cloud Run 03 — 2026-04-30

## Purpose

Add a thin FastAPI adapter over the existing transport boundary without changing the core contracts, catalog service, or transport handler behavior.

This run introduces real HTTP route wiring for local tests only. It must remain pre-alpha, local-development focused, and non-deployed.

## Current Repository Context

The `develop` branch already contains:

- Python package baseline
- contract dataclasses
- deterministic error helpers
- in-memory synthetic factor catalog service
- transport response envelopes
- status mapping
- serialization helpers
- local route-handler-like functions
- API contract and architecture documentation
- transport boundary documentation
- test-only CI

## Design Decision for This Run

Add FastAPI only as a thin adapter layer.

The FastAPI layer must reuse existing transport handlers and envelopes. Do not duplicate business logic inside route functions.

Do not add deployment, Docker, hosting, database, authentication, or external API behavior.

## CFA-011 — Factor Routes Backed by Transport Handlers

### Objective

Add thin HTTP routes that delegate to existing transport handler functions.

### Required Changes

Create or update:

```text
src/carbonfactor_api/http/routes.py
src/carbonfactor_api/http/app.py
tests/test_http_routes.py
```

### Route Requirements

Add routes such as:

```text
GET /factors
GET /factors/{factor_id}
```

Behavior:

- `/factors` should map query parameters to `handle_list_factors(query)`.
- `/factors/{factor_id}` should map to `handle_get_factor(factor_id)`.
- Routes must use transport envelopes/status mapping.
- Route functions should not duplicate catalog business logic.
- Returned payloads should match existing transport handler output.

### Tests

Add tests for:

- `GET /factors` success
- `GET /factors?category=...` success
- `GET /factors/{id}` success
- `GET /factors/{missing}` returns not-found status and error payload
- route payload matches transport handler payload for representative cases

### Completion Criteria

- routes delegate to transport handlers
- no duplicated core logic
- `python -m pytest -q` passes
- commit created

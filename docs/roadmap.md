# Roadmap

This roadmap lists near-term technical improvements that fit the current API foundation. These items are not implemented in this batch.

## Near-Term Work

- CSV and Excel import support with per-row validation output.
- Richer factor source metadata, including dataset name, publication reference, and version labels.
- Versioned factor datasets so consumers can query by dataset release.
- Persistence provider abstraction for durable storage.
- Audit trail for record creation and import activity.
- Authentication and authorization for protected write operations.
- Rate limiting for public-facing deployments.
- Background import jobs for larger datasets.
- Improved OpenAPI examples for every endpoint.
- Health checks that distinguish process health from storage provider health once durable storage exists.

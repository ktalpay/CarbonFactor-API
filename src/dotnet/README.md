# CarbonOps-API .NET

This directory is the planned .NET implementation root for CarbonOps-API.

## Current Status

- No `.sln` or `.csproj` files are added in this phase.
- No .NET runtime implementation is included yet.
- The current repository behavior remains provided by the Python implementation
  under `src/python`.

## Planned Direction

The future .NET path is intended to host an independent CarbonOps-API
implementation that preserves the same public API semantics while using
.NET-oriented project structure and tooling.
